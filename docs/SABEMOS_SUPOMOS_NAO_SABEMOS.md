# Sabemos, supomos e não sabemos

## Sabemos

- A ONG precisa controlar presença e frequência.
- O sistema deve ser simples para pessoas com pouca experiência digital.
- A disciplina exige Java, Spring Boot, MVC, H2, JPA e Thymeleaf.

## Supomos

- Atividade pode representar turma, grupo, modalidade ou oficina.
- A ausência justificada deve aparecer separada nos relatórios.
- Desativar é mais seguro do que excluir participantes com histórico.
- O cadastro inicial de participante precisa apenas de nome e observações.

## Não sabemos

- Quais campos pessoais a ONG realmente precisa guardar.
- Como a ONG define frequência mínima.
- Se justificativa conta ou não para frequência oficial.
- Quantas atividades acontecem por semana.
- Quantas pessoas registram presença.
- Se haverá perfis como ADMIN e OPERADOR.
