# Escopo preliminar

## Objetivo

Criar um sistema web para controle de presença e frequência dos participantes da ONG Remo Meu Rumo.

## Dentro do escopo inicial

- Participantes.
- Atividades.
- Encontros.
- Presenças.
- Histórico.
- Frequência.
- Indicadores.
- Relatórios simples.
- Exportação CSV.
- Ajuda.
- Acessibilidade.
- API REST.

## Fora do escopo inicial

- Autenticação e autorização completas.
- Dados reais da ONG.
- Integrações externas.
- Regras definitivas de frequência mínima.
- Campos pessoais sensíveis sem confirmação.

## Observação

Este escopo deve ser revisado após a entrevista com a ONG.
